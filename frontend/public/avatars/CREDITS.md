# Default avatars

`avatar-01.svg` … `avatar-20.svg` are the "Fun Emoji" style by Davis Uche,
generated via DiceBear (https://www.dicebear.com/styles/fun-emoji/),
licensed under CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/).

They are assigned to users without an uploaded photo by
`frontend/src/utils/avatar.js` (stable hash of the user id).
