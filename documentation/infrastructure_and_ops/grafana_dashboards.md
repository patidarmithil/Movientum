# Monitoring (App Insights + Grafana)

The backend sends traces, metrics and logs to **Azure Application Insights** using OpenTelemetry. **Grafana** dashboards read that data.

## Setup (`backend/app/telemetry.py`)

- Uses the `azure-monitor-opentelemetry` package.
- Needs `APPLICATIONINSIGHTS_CONNECTION_STRING`. If it is missing, telemetry is skipped with a warning and the app runs normally.
- FastAPI requests and Celery tasks are traced automatically (Celery through task signals).

## Metric types

- **Counter** — only goes up (e.g. number of feedback signals).
- **Histogram** — timings (e.g. how long a PageRank walk took).
- **Observable gauge** — a current value read on demand (e.g. graph node count).

## Custom metrics

| Area | Metric | Type | Meaning |
|---|---|---|---|
| Recs | `movientum_rwr_seconds` | Histogram | PageRank walk time |
| Recs | `movientum_feature_matrix_build_seconds` | Histogram | 16-feature matrix build time |
| Recs | `movientum_xgb_inference_seconds` | Histogram | Ranker scoring time |
| Recs | `movientum_xgb_coldstart_total` | Counter | Rankings done without an approved model |
| Graph | `movientum_graph_node_count`, `_edge_count` | Gauge | Graph size |
| Graph | `movientum_graph_rebuild_duration_seconds` | Histogram | Graph build time |
| Retrain | `movientum_retrain_total` | Counter | Outcome: success / skipped / not approved / error |
| Retrain | `movientum_retrain_duration_seconds` | Histogram | Job time |
| Retrain | `movientum_retrain_rows_trained` | Gauge | Rows used |
| Feedback | `movientum_feedback_signals_total` | Counter | Thumbs/clicks processed |
| Feedback | `movientum_taste_profile_update_seconds` | Histogram | Profile update time |
| Cache | `movientum_cache_operations_total` | Counter | Hits and misses by key type |
| Celery | `movientum_celery_task_total`, `_duration_seconds` | Counter / Histogram | Background job runs and timings |

## Grafana

- Dashboard JSON lives in `backend/grafana/` and is generated by `backend/scripts/generate_dashboards.py` from the metric list.
- Dashboard URLs are in `backend/.env` and linked from the admin panel's "API & Infra" tab.
- `backend/scripts/test_app_insights.py` sends a test metric to check the pipeline.

## Other monitoring

- `GET /api/health` → `{status, version, environment, dependencies: {database, cache}}`, 503 if either is down.
- Frontend page analytics: self-hosted Umami, proxied through Vercel at `/st/*`, plus Vercel Analytics.
